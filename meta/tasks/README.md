# meta/tasks — task files

This folder holds the task files of Diogenes 0.0-min ([`../roadmap/0.0/MIN.md`](../roadmap/0.0/MIN.md), gate M3) and after. Their convention:

- **One file per task:** `meta/tasks/<date>-<item>.md`, a tracked path, with the task template's required lines in order (`MIN.md`, "Decisions, rules and size"). The template itself, `docs/TASK-TEMPLATE.md`, is written by the build. It is on `main` since build step 5's merge, `3ab3115` (2026-10-18).
- **The merger, diogenes' one writer of `main` (the `merger` line of [`../ROLES.md`](../ROLES.md)), commits each task file on `main` for its poster.** `posted-by` names the poster, and the commit message names the poster's message: its sender and its clock time.
- **Delivery:** after committing a task file, the merger pushes `main`, and the Team seat pulls `main` before it branches (`/home/randy/Team/CLAUDE.md`: "pull before starting work and before pushing").
- **The Team seat works a Team task in its own clone,** `/home/randy/Team/REPOS/diogenes`. It fills `report:` on its branch `team/diogenes-<item>` and pushes, and it never edits the Workspace copy.
- **For a credits-job or subagent task, the poster's seat fills `report:`** on a Workspace branch, from the runner's output path or the subagent's REPORT block.
- **`verified-by:` is filled on `main` at merge by the verifier:** the merger for a Team task; for a credits-job or subagent task, a seat or verifier subagent other than the reporter. **Note 2026-10-18, `diogenes_1`, at build step 5's merge (`3ab3115`):** as `docs/TASK-TEMPLATE.md`'s decisions T1 and T2 read this line, it names the verifier, and the merger commits it on `main`, with `merged-at`, in its first commit after the merge commit, since only the merger writes `main` (rule 4).
- **The poster line is in [`../ROLES.md`](../ROLES.md),** which the merger commits on `main`. Outside the gate, the merger commits no task file from a sender off the poster line: it holds the file and asks the ecosystem manager (`management_N`). The one exception is M3's fourth task, posted by `probe-m`, which is not on the poster line: the merger commits it all the same, so that the Team seat's refusal (`refused: poster`) is what gets tested.
