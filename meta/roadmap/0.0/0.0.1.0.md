
**Conventions every module keeps:**
- `now()` returns `datetime.now(timezone.utc).strftime('%Y-%m-%dT%H:%M:%SZ')`; no other time source (RULES §5). ISO strings in this fixed form compare correctly as text.
- `open_store()` opens `DIO_HOME/store/diogenes.db` with `timeout=5`, `isolation_level=None`, runs `PRAGMA busy_timeout=5000; PRAGMA foreign_keys=ON`, and returns the connection. Writes use `BEGIN IMMEDIATE … COMMIT` explicitly.
- `DIO_HOME` is `os.environ.get('DIO_HOME') or os.path.expanduser('~/.local/share/diogenes')`; the override exists for tests and is documented as such (same uid cannot be defended against in 0.0; DESIGN §5).
- Exit codes: `0` ok; `1` refused (first line `refused: <reason>`); `2` usage; `3` `identity unknown: pass --session <id from your transcript path>`.
- `--json` on read commands prints one JSON object or array and nothing else.
- Every row's provenance: `by_identity`, `by_session`, `by_call` (the argv subcommand, e.g. `send`), `by_transport` (`direct-file` for Bash and the terminal, `hook` for hook commands), `at`.

`next_seq(conn)` is `UPDATE counter SET value = value + 1 WHERE name = 'seq' RETURNING value`, run inside the caller's `BEGIN IMMEDIATE` (RETURNING needs SQLite ≥ 3.35; 3.45.1 has it). Message ids are `m<seq>`, task ids `t<seq>`, one cursor family (RULES §7).

## 3. Steps

### Step 1: scaffold and `store`

Create the files in §1. `src/dio.py`:

```python
#!/usr/bin/env python3
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from diogenes.cli import main
sys.exit(main())
```

`store.py` commands:

| Command | Does | Prints |
|---|---|---|
| `dio store init` | creates `DIO_HOME/{store,backups,spool,log}` with mode 0700 and the db with mode 0600; applies `schema.sql` when `schema_version` is absent; refuses if present with a different version | `store: <path> schema 1 (created)` or `(present)` |
| `dio store backup` | `conn.backup()` to `DIO_HOME/backups/diogenes-<UTC compact>.db`, then `PRAGMA integrity_check` on the copy | `backup: <path> ok (<bytes> bytes)` |
| `dio store check` | `PRAGMA integrity_check; PRAGMA wal_checkpoint(PASSIVE)`; counts per table | `check: ok; sessions N identities N messages N tasks N leases N` |
| `dio store path` | | the db path |

`dio store init` is also run implicitly by any command when the db is absent? **No.** A missing store is `refused: no store at <path>; run dio store init` (exit 1), so a misconfigured `DIO_HOME` never creates a stray store.

### Step 2: the CLI tree

`cli.py` builds `argparse` with subparsers `store`, `register`, `role`, `who`, `project`, `presence`, and (added by later subcycles) `send inbox ack sent owed lock task meters credits wait hook adapter`. Global options: `--home PATH` (same as `DIO_HOME`), `--session ID`, `--json` (accepted everywhere, honoured by reads). `dio --version` prints `dio 0.0 (schema 1)`.

### Step 4: caller resolution (DR-107)

`resolve_caller(args, env, stdin_hook=None)` returns `(identity_row, session_row, how)` in this order, stopping at the first that resolves:

1. `stdin_hook['session_id']` when the command is a `hook` subcommand (how `hook-stdin`).
2. `args.session` when given: the session row must exist, else `refused: unknown session <id>; register first` (how `explicit`).
3. `env['CLAUDE_CODE_MESSAGING_SOCKET']` when set: the session row whose `socket_path` equals it and `ended_at IS NULL`; if none, `refused: socket not registered; run dio register (or the SessionStart hook did not run)` (how `socket-map`).
4. `sys.stdin.isatty()` and the file `DIO_HOME/terminal-identity` exists: identity `author`, session `terminal` (how `terminal`).
5. Otherwise exit 3 with `identity unknown: pass --session <id from your transcript path>`.

A caller-supplied `--from` or `--as` does not exist (RULES §2). Every write stores `by_identity`, `by_session`, `by_transport` = `hook` for rule 1, else `direct-file`.

### Step 5: `register`, `project`, `role`

```
dio project add PROJECT [--orchestrator-role ROLE]
dio register --name NAME --session ID --how HOW --account A [--executor K] [--pid P] [--socket S] [--transcript T] [--cwd C] [--ref R] [--project P] [--model M]
dio register --terminal                       # tty only; creates identity 'author' (kind author, account terminal) and DIO_HOME/terminal-identity
dio role assign ROLE --to IDENTITY [--how handoff|author]   # creates the role if absent, project from the role's prefix mapping (--project P when ambiguous)
dio role show PROJECT | dio role history ROLE
dio presence set parked-on-purpose|quota-paused|clear
```

`register` rules:
- Creates the identity when absent: `kind` from `--executor` (`team-session` → worker, `credits-job` → job, none → seat); refuses a reserved name; refuses when the identity exists with a different account (`refused: nitpick-libs_18 is registered under max, not team`).
- Creates or refreshes the session row keyed by `--session`: on refresh updates `pid, pid_start, socket_path, name, ref, last_seen_at, last_seen_how='call'`, clears `ended_at`.
- **Never touches `role`** (DR-106). A `--role` flag does not exist.
- `pid_start` is read by `register` itself from `/proc/<pid>/stat` field 22 when `/proc/<pid>` is readable; `pid_how` records `socket-basename`, `ancestor-walk` or `given`.
- Prints `registered nitpick-libs_18 (seat, max) session 7702a1… how hook-stdin pid 3361843`.

`role assign`: `BEGIN IMMEDIATE`; writes `role.holder` and one `role_event` with `by_identity` from the caller, `how` from the flag (default `author` when the caller is `author`, else `handoff`); refuses when `--to` is not a registered identity; refuses when the caller is a worker (kind `worker` or `job`): `refused: a worker cannot assign roles`. Prints `libs-seat: nitpick-libs_18 → nitpick-libs_19 (handoff by nitpick-libs_18, <at>)`.

### Step 6: `who` and the process check (DR-17, DR-108)

`process_check(session)`: returns `alive`, `dead` or `impossible`:
- `impossible` when `pid IS NULL`, or `/proc` is not readable for that pid from here (`PermissionError`, or DX-3 found the sandbox hides host pids and the caller's transport is `direct-file` from a non-tty).
- `alive` when `/proc/<pid>/stat` exists and its field 22 equals `pid_start` (or `pid_start IS NULL`), and, when `socket_path` is set, `os.path.exists(socket_path)`.
- `dead` otherwise.

`who` computes each session's state:

| Condition | State |
|---|---|
| `ended_at` set | `gone` |
| `manual_state` set | that state |
| check `alive` and `last_seen_at` within `presence_grace_s` (fact, default 1800) | `live` |
| check `alive` and older | `live-idle` |
| check `dead` and `last_seen_at` older than the grace | `gone` |
| check `dead` within the grace | `unknown` (a restart may be in progress) |
| check `impossible` | `unknown`, shown with `last check <age> by <hook|terminal>: <result>` when a check exists |

Every `who`, every `hook inject` and every `hook status-line` call that can check writes `last_check_at`, `last_check_result`, `last_check_by` for every open session (microseconds each), so a sandboxed `who` shows a recent check.

Output (fixed columns; `--json` gives every DR-16 field: `identity, role, executor_kind, session_id, session_id_how, pid, pid_start, socket_path, name, ref, account, harness, state, last_seen_at, last_seen_how, last_check_at, last_check_result, ctx_pct, wait, modes`):

```
account  identity         role       session   state      last seen            ctx   wait  kind
max      nitpick-libs_18  libs-seat  7702a1    live-idle  41 m ago (status-line)  41 %  -     seat
team     libs-worker_1    -          9c0d2e    live       2 m ago (call)          12 %  wait  team-session
```

`modes` in 0.0 is `poll,inject` for a session registered by a hook, `poll` otherwise, plus `wait` when `wait_since` is set. `--project P` filters by identity project.

## 5. Risks

- **`RETURNING` unsupported** in the Python library's SQLite: block S in 0.0.0.0 printed the version; if under 3.35, `next_seq` becomes `UPDATE …; SELECT value …` inside the same `BEGIN IMMEDIATE`, which is equivalent under the write lock.
- **`/proc/<pid>/stat` field 22 when the comm has spaces**: parse after the last `)`.
- **Tests that read the test runner's own pid** depend on `/proc`; fine on this machine.
- **A subcommand grows large**: keep each module under 400 lines; split before adding.
