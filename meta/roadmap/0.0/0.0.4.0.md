## 2. Scripts (`tests/gate/`)

- `messages.sh SIDE PEER N`: sends N messages `dio send PEER --kind request --reply reply-expected --subject "gate SIDE i"`, then waits (poll `dio inbox --count` every 5 s, up to 10 minutes) until N messages from PEER are unread, lists them with `dio inbox`, acks them, and prints `SIDE: sent N, received N, acked N`.
- `tasks_post.sh N EXECUTOR ROUTE`: for i in 1..N writes `meta/tasks/gate-<EXECUTOR>-<i>.md` (a spec whose acceptance command is `test -f meta/tasks/gate-<EXECUTOR>-<i>.md`), commits and pushes, and posts each with `dio task post --project diogenes --executor EXECUTOR --route ROUTE --model opus --spec meta/tasks/gate-<EXECUTOR>-<i>.md`; prints the ids.
- `tasks_verify.sh`: for every task of mine in `reported`, re-runs the acceptance command from the spec (`git cat-file -p <blob>` → the line after `acceptance:`), writes the output to `.internal/gate/verify-<id>.log`, and runs `dio task verify <id> --verdict pass|fail --evidence <log path> --label gate-verifier`.
- `wait_trials.sh N`: the orchestrator side of G6: for i in 1..N, waits until `dio who --json` shows the worker with `wait`, records the clock, posts one task (as `tasks_post.sh 1 team-session team`), and polls `dio task show` until `claimed`; prints `trial i: posted <t>, claimed after <s> s`.
- `relay_log.md`: a file both seats append to, one line per gate step, each with `relay: none` or the relay that happened.
