## 2. DX-1 (revised): SQLite compare-and-set across the sandbox boundary

Decides the shape of everything from 0.0.1.0 on (DQ-1).

### Step 1: write the probe files (executor, Bash in `$P`)

```sh
# block 1a
cd "$P"
sqlite3 probe.db 'PRAGMA journal_mode=wal; CREATE TABLE lease(id TEXT PRIMARY KEY, holder TEXT, fence INTEGER NOT NULL DEFAULT 0, expires_at REAL);'
sqlite3 probe.db "INSERT INTO lease VALUES('t', NULL, 0, 0);"
cat > take.py <<'EOF'
import os, sqlite3, sys, time
me, mode, seconds, db = sys.argv[1], sys.argv[2], float(sys.argv[3]), sys.argv[4]
wins = rounds = errors = 0; end = time.time() + seconds
def take(ttl):
    c = sqlite3.connect(db, timeout=5, isolation_level=None)
    c.execute('PRAGMA busy_timeout=5000'); c.execute('BEGIN IMMEDIATE')
    r = c.execute("UPDATE lease SET holder=?, fence=fence+1, expires_at=? WHERE id='t' AND (holder IS NULL OR expires_at<?)",
                  (me, time.time()+ttl, time.time())).rowcount
    c.execute('COMMIT'); c.close(); return r
if mode == 'free':
    while time.time() < end:
        try: wins += take(0.001)
        except sqlite3.OperationalError as e: errors += 1; print('ERR', e, flush=True)
        rounds += 1
else:
    d = os.path.dirname(db)
    while time.time() < end:
        rounds += 1
        while not os.path.exists(os.path.join(d, f'go.{rounds}')):
            if time.time() > end: break
            time.sleep(0.005)
        if time.time() > end: rounds -= 1; break
        try: wins += take(60)
        except sqlite3.OperationalError as e: errors += 1; print('ERR', e, flush=True)
print(me, mode, 'rounds', rounds, 'wins', wins, 'errors', errors)
EOF
cat > rounds.sh <<'EOF'
#!/bin/sh
# referee: one round per second, clearing the lease between rounds
cd "$(dirname "$0")"; i=1; end=$(( $(date +%s) + $1 ))
while [ "$(date +%s)" -lt "$end" ]; do
  sqlite3 probe.db "UPDATE lease SET holder=NULL, expires_at=0 WHERE id='t';"
  touch "go.$i"; sleep 1; i=$((i+1))
done
echo "referee rounds $((i-1))"
EOF
chmod +x rounds.sh; ls
```

Expected: `probe.db  probe.db-wal  probe.db-shm  rounds.sh  take.py` (the WAL files may appear after the first write).

### Step 2: free-running, host versus sandbox, overlapping

`[author]` in a terminal, at the moment the executor says go:

```sh
cd <P> && python3 -I take.py A free 20 probe.db > log/dx1-A-free.txt 2>&1 &
```

The executor, in the same moment, as a background Bash call: `cd "$P" && python3 -I take.py B free 20 probe.db > log/dx1-B-free.txt 2>&1`. After both end:

```sh
# block 1b
cd "$P"; cat log/dx1-A-free.txt log/dx1-B-free.txt; sqlite3 probe.db 'SELECT fence FROM lease;'
```

Expected: two lines `A free rounds N wins W_A errors 0`, `B free rounds M wins W_B errors 0`, and `fence == W_A + W_B`. Any `ERR database is locked` line is a fail of this leg.

### Step 3: contested rounds, host versus sandbox

```sh
# block 1c (executor): reset
cd "$P"; rm -f go.*; sqlite3 probe.db "UPDATE lease SET holder=NULL, fence=0, expires_at=0 WHERE id='t';"
```

`[author]`: `cd <P> && ./rounds.sh 30 > log/dx1-ref.txt 2>&1 & python3 -I take.py A contested 30 probe.db > log/dx1-A-con.txt 2>&1 &`. The executor at the same moment, background Bash: `cd "$P" && python3 -I take.py B contested 30 probe.db > log/dx1-B-con.txt 2>&1`. Then:

```sh
# block 1d
cd "$P"; cat log/dx1-ref.txt log/dx1-A-con.txt log/dx1-B-con.txt; sqlite3 probe.db 'SELECT fence FROM lease;'; ls go.* | wc -l
```

Expected: `referee rounds R`; `wins_A + wins_B == R` (a racer may count one round more or less at the edges; the sum of wins against the referee's count is the assertion, within 1); `fence == R`; `errors 0`.

### Step 4: contested rounds, both racers sandboxed (two accounts' sandboxes modelled)

Reset as block 1c. `[author]` runs only the referee: `cd <P> && ./rounds.sh 30 > log/dx1-ref2.txt 2>&1 &`. The executor starts **two** background Bash calls, each `cd "$P" && python3 -I take.py <A|B> contested 30 probe.db > log/dx1-<A|B>-con2.txt 2>&1`. Assert as block 1d.

### Decision

| Result | Decision |
|---|---|
| All four legs: no errors, fence equals wins, one winner per round | **DQ-1 (a) stands.** 0.0.1.0 proceeds |
| Fails on the host alone (step 2 or 3 with errors) | stop; a spool-ingesting hub moves into 0.0 (ROADMAP "Order"); re-plan 0.0.1.x before writing code |
| Passes on the host, fails only across the boundary (steps 2 to 4) | stop; Bash use of `dio` is dropped for hooks-only and the spool hub moves in; re-plan |

## 7. DX-13: a background `until` loop wakes the session, every time, and its cap

### Step 1: the short wait, in `probe-a` (`[author]` opens; the executor writes the loop text)

### Step 2: the 2-hour and overnight waits

Same loop, `rm` the go file first; leave 2 hours; touch; record. Then overnight (`sleep 30` loop, 8+ hours); in the morning touch and record whether the loop was still running (`ps -ef | grep -c 'sleep 30'` before the touch) and whether the wake came.

### Step 3: the `data_version` shape

In `probe-a`, background: `python3 -c "import sqlite3,time; c=sqlite3.connect('<P>/probe.db'); v=c.execute('PRAGMA data_version').fetchone()[0]
while c.execute('PRAGMA data_version').fetchone()[0]==v: time.sleep(30)
print('WAKE data_version changed')"`. After 5 minutes, from a terminal: `sqlite3 <P>/probe.db "UPDATE lease SET holder='x' WHERE id='t';"`. Expected: the wake within 30 s. Note: M4 measured `data_version` changing across connections after a commit; this leg confirms it from the polling shape `dio wait` uses with one long-lived connection, which is DX-7's "no long concurrent reads" concern — if it does not change, `dio wait` reconnects per poll (0.0.2.2 step 1 has both).

### Decision

| Finding | Effect |
|---|---|
| Wakes at 10 min, 2 h and overnight | `dio wait --max` default 8 h; G6 measured against a single wait |
| Wakes at 10 min and 2 h, not overnight | `--max` default 1.5 h; `dio wait` prints a re-arm line; G6 measured against the re-armed loop (ROADMAP "Order") |
| Does not wake at 10 min | stop; `dio wait` stays in the code as a poll-only helper, G6 is reported as not met with the measurement, and the day-zero doorbell or the author's hand remains until 0.2 |
