### Step 2: the Max settings fragment (`[author]` merges into `~/.claude/settings.json`)

The executor writes `src/adapter/settings-max.json` and prints it with `dio adapter print-settings --account max --then '<the author's current statusLine command, read from his settings with the Read tool>'`:

```json
{
  "hooks": {
    "SessionStart": [{"hooks": [{"type": "command", "command": "python3 -I /home/randy/Workspace/REPOS/diogenes/src/dio.py hook session-start --account max", "timeout": 5}]}],
    "UserPromptSubmit": [{"hooks": [{"type": "command", "command": "python3 -I /home/randy/Workspace/REPOS/diogenes/src/dio.py hook inject --account max", "timeout": 5}]}],
    "PostToolUse": [{"hooks": [{"type": "command", "command": "python3 -I /home/randy/Workspace/REPOS/diogenes/src/dio.py hook inject --account max", "timeout": 5}]}]
  },
  "statusLine": {"type": "command", "command": "python3 -I /home/randy/Workspace/REPOS/diogenes/src/dio.py hook status-line --account max --then '<ORIGINAL COMMAND>'"},
  "env": {"CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "0"},
  "sandbox": {"filesystem": {"allowWrite": ["/home/randy/.local/share/diogenes"]}}
}
```

Merge rules the author follows: hook arrays are **appended** to existing ones (his context-warning `PostToolUse` hook stays); `statusLine` **wraps** his command (quoted once; if it contains a single quote, the executor prints a `--then-file` variant that reads the command from `DIO_HOME/statusline-max.cmd`); `env` and `sandbox.filesystem.allowWrite` are merged, not replaced. Then `dio adapter check --account max` (the executor) reads `~/.claude/settings.json` with the Read tool's privilege (through Python, outside the sandbox? No: `adapter check` is run by the **author** in a terminal, or by the executor through a hook-free path) and prints `max: hooks 3/3, statusLine wrapped, agent-teams off, allowWrite present`.

New sessions pick the hooks up; a session already open needs `/hooks` reload or a restart. The `allowWrite` entry took effect without a restart when observed (CONSTRAINTS §3).
