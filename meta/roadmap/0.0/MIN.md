## Summary for the author

- `dio who`: presence read from Claude Code's own `sessions/<pid>.json` under both config dirs, with a process check, a prefix listing, and role resolution from a tracked role line.

**Step 1. `dio who` from the sessions files.** Python 3 standard library (DQ-2):

- For each of `~/.claude/sessions/` and `~/.claude-team/sessions/`, `os.scandir`, keep only names matching `^[0-9]+\.json$`, discard every other entry without logging it. Open each match with `O_NOFOLLOW` and refuse anything that is not a regular file. No shell globbing, and no code path ever lists, opens or names a `.key` file.
- Parse strictly: `pid` as int, `procStart`, `messagingSocketPath` required; `sessionId`, `cwd`, `startedAt`, `name`, `status`, `updatedAt` optional. Record the Claude Code version at first read. On any mismatch print `unknown (sessions format: <version>)`. A file caught mid-rewrite counts as a mismatch for that pass.
- Process check per DR-108: `/proc/<pid>` exists, its start time equals `procStart`, the socket file exists. `status` supplies `live` or `live-idle`; this is the file's own idle flag, not DR-17's heartbeat age, and `USING.md` says so. The account is the directory read.
- Output: `dio who` lists both accounts. `dio who --prefix <p>` lists live sessions whose `name` starts with `<p>`, sorted by the trailing `_N`. `dio who --address <x>`: if `<x>` is a role on the role line, `meta/ROLES.md` (step 5, decision 3), print the holder's socket; if it is an exact live name, print its socket; if it is a bare prefix with exactly one live match, print that; with several, print them all and `ambiguous: <n> live`, exit non-zero, and pick the highest only under `--highest`. A brief cites `dio who --address libs-seat`, never a socket path.
- Grace for `gone`: 60 seconds, held in a small cache under `~/.local/share/diogenes/cache/` of the first failed check per entry, keyed by config dir and pid, so both accounts' runs share one file set without a conflict (DR-17, `meta/REQUIREMENTS.md:43`). `unknown (checking)` until the grace passes, then `gone`.
