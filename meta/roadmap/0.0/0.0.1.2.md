## 1. Commands

```
dio lock take ID --ttl DUR          # DUR: 90s | 15m | 2h; max 24h
dio lock release ID
dio lock renew ID --ttl DUR         # holder only; same fence; new expiry
dio lock status ID [--json]
dio lock takeover ID --reason TEXT  # a recorded takeover; refused while the holder's session reads live (who's state)
```

Lease id: exact three-part form (0.0.1.0 §3 step 3); the row is created on first `take` (`lease_event 'create'`). **Exact match only** (DR-34): no prefix, glob or substring; `status pa/tree/me` never matches `pa/tree/names`.

### `take` (DR-30, DR-32, DR-36)

```sql
BEGIN IMMEDIATE;
INSERT OR IGNORE INTO lease(id, project, layer, resource) VALUES (?, ?, ?, ?);
UPDATE lease SET holder=?, holder_session=?, fence=fence+1, taken_at=?, ttl_s=?, expires_at=?, released_at=NULL, release_kind=NULL
  WHERE id=? AND (holder IS NULL OR expires_at < ?);          -- the compare-and-set; ? = now()
-- rowcount 1: taken; before COMMIT, if the previous row had a holder and expires_at < now, insert lease_event 'expiry' for the old holder
-- rowcount 0: insert lease_event 'refused' and COMMIT; print the refusal
COMMIT;
```

No local or cached read is consulted: the only read is the one inside the transaction (DR-32). Prints `taken nitpick-libs/tree/workbench fence 17 until 2026-10-10T16:02:11Z (2h)`. Refusal: `refused: nitpick-libs/tree/workbench held by nitpick-libs_18 (fence 17) until <expires_at>`.

### `release` (DR-31)

One statement: `UPDATE lease SET holder=NULL, holder_session=NULL, fence=fence+1, released_at=?, release_kind='holder' WHERE id=? AND holder=?` (the caller's identity). rowcount 0 → `refused: you do not hold <id> (holder: <x> | free | absent)`. Prints **the announcement, generated from the row**, the only source of release text:

```
released nitpick-libs/tree/workbench at 2026-10-10T15:40:02Z; fence 17 → 18; the next take gets 19
```

There is no `announce` command (DR-31's verify).

### `status` (DR-33, DR-36)

| Row | Prints |
|---|---|
| none | `nitpick-libs/tree/workbench: absent` (exit 0; a guard treats `absent` as not held) |
| holder NULL | `…: free (fence 18, released <at> by holder)` or `(… by takeover)` |
| holder set, `expires_at >= now` | `…: held by nitpick-libs_18 (fence 17) until <expires_at>, <remaining>` |
| holder set, `expires_at < now` | `…: expired (was nitpick-libs_18, fence 17, expired <at>); the next take succeeds` |

`absent` and `free` are distinct states, and neither permits a write without a take (DR-33); `docs/USING.md` says so in those words.

### `renew` and `takeover`

`renew`: holder only, `expires_at = now + DUR`, fence unchanged, `lease_event 'renew'`. `takeover`: refused when the lease is absent or free (`refused: <id> is absent|free (fence N); take it`, exit 1, no event, no fence change); refused when `who` computes the holder's session as `live` or `live-idle` (including by a recorded check younger than the grace, 0.0.1.0 step 6); allowed when `gone`, `unknown` past the grace, or expired; writes `holder=NULL, fence=fence+1, release_kind='takeover'` and `lease_event 'takeover'` with the reason; prints the same announcement form with `(takeover by <caller>: <reason>)`.

```python
import os, subprocess, sys, time
me, seconds, home, dio = sys.argv[1], float(sys.argv[2]), sys.argv[3], sys.argv[4]
ns = ' '.join(os.readlink(f'/proc/self/ns/{n}') for n in ('net', 'pid'))
t0 = time.time()
while not os.path.exists(f'{home}/go.start'):
    if time.time() > t0 + 120: print(me, 'no go.start within 120 s'); sys.exit(1)
    time.sleep(0.02)
wins = rounds = 0; end = time.time() + seconds
while time.time() < end:
    rounds += 1
    while not os.path.exists(f'{home}/go.{rounds}'):
        if time.time() > end: break
        time.sleep(0.005)
    if time.time() > end: rounds -= 1; break
    r = subprocess.run(['python3','-I',dio,'--home',home,'--session',me,'lock','take','nitpick-libs/tree/race','--ttl','60s'], capture_output=True, text=True)
    wins += (r.returncode == 0)
print(me, 'rounds', rounds, 'wins', wins, 'ns', ns)
```

H=$1; D=$2; i=1; end=$(( $(date +%s) + $3 )); touch "$H/go.start"

sleep 1; python3 -I "$D" --home "$H" --session REF lock takeover nitpick-libs/tree/race --reason "final" >/dev/null 2>&1
echo "referee rounds $((i-1)) ns $(readlink /proc/self/ns/net)"; python3 -I "$D" --home "$H" --session REF lock status nitpick-libs/tree/race
